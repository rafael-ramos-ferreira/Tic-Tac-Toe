# 🃏 CLI Tic-Tac-Toe

## _Your favorite game at a command of distance_

### What's this?

This is a simple tic-tac-toe game wrote in `Python` that runs directly 
in the terminal and allows you to play with as many friends as you wish
in a board with the size you desire (size *should* be an odd number).

### How to use?

You just need to have the `main.py` file on the folder you wish and
run the following command on your terminal:

> python3 main.py

Then... **just have fun!**

#### ❗ Note:

To change configs such as size of the board or number of players you 
need to edit the constants in the `main.py` file.
